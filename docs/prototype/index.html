Prompt Registry / console

Prototype · synthetic data

Design mockup for the prompt-registry repository — a prompt is code: versioned, immutable, tested, promoted, and rolled back. Rollback is one operation, because the previous version is still there. Built on the shadcn/ui token system. Figures are illustrative.

v8 failed the regression gate — 42% win-rate vs v7 on the golden set. Rollback was possible because v7 is immutable and still present. v8 stays in staging for inspection; nothing was overwritten.
