@ prompt-registry docs-first · now runnable

A prompt is code — version it, test it, promote it, roll it back.

A registry that treats a prompt as a versioned, immutable artifact with an identity, a test, a promotion path, and a rollback. Documented first — and now runnable end to end, from one command.
